# Reference design index

Use [Semtech SX1262 reference designs](https://www.semtech.com/products/wireless-rf/lora-connect/sx1262), [Espressif hardware guidance](https://documentation.espressif.com/esp-hardware-design-guidelines/en/latest/esp32s3/index.html), [RP2040 hardware design guide](https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf), and the manufacturer resources linked in [power options](../../docs/POWER_ARCHITECTURE_OPTIONS.md).

Links are starting points. Before reuse, record exact revision, matched variant, license/terms, source files and modifications in [reuse register](../../references/REUSE_REGISTER.md). Do not vendor copyrighted reference files without checking redistribution terms. No circuit/layout assets have been copied.
